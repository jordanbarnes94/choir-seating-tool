# Choir Seating Tool Manual

The user manual, one page for each part of the app. In the app, open it with the **Manual** link
at the bottom of the page.

1. [Getting started](getting-started.md): what Choir Seating Tool does, and a first seating plan in four steps.
2. [Choir setup](choir-setup.md): rosters of singers, concerts, who is singing, splits, and importing a spreadsheet.
3. [The stage](the-stage.md): reading the stage, the two views, colouring by split, and grid size.
4. [Arranging](arranging.md): Auto-arrange, section order, Compact, moving and locking singers, the waiting area, Block and Space.
5. [Neighbour check](neighbour-check.md): what alone, split and ↕ mean, how they show on the stage, and pointing at a problem to find it.
6. [Seating plans](seating-plans.md): several plans per concert, saving changes, and comparing one plan with another.
7. [Walk-on order](walk-on-order.md): the order singers file on, so a queue can form backstage.
8. [Printing and export](print-and-export.md): printing or saving a PDF, print options, spreadsheet exports, and which way round the plan is drawn.
9. [Settings and backup](settings-and-backup.md): colours, seat labelling, keeping a backup, and using Choir Seating Tool as an app.
